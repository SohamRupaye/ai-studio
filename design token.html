Design Tokens

Named, versioned building blocks of the AI Studio design system. Every color, spacing value, typeface, elevation, and motion value comes from a token. Apply via CSS custom property or import from @ai-studio/ui/tokens.

Font

Font tokens encode the complete CSS font shorthand — size, weight, line-height, and family — in a single variable. Always apply using CSS font:, not font-size, so size is never decoupled from its companion weight and typeface.

Primitives

Six perceptually-tuned 11-step color ramps. Semantic tokens (--primary, --highlight…) reference these — never hardcode a hue. Apply via hsl(var(--indigo-500)). Primitive ramps are mode-agnostic; semantic tokens choose the right step per mode.

Motion

Duration and easing tokens prevent transition: all .2s from spreading across the codebase. Always pair a duration with an easing: transition: opacity var(--dur-base) var(--ease-std). Motion tokens are mode-agnostic.

Easing
easing.standard
cubic-bezier(0.2, 0, 0, 1)
Default. Elements staying on screen decelerate to rest. Use for color, opacity, shadow.
easing.decelerate
cubic-bezier(0, 0, 0, 1)
Elements entering the viewport — panels sliding in, dialogs mounting. Arrives softly.
easing.accelerate
cubic-bezier(0.3, 0, 1, 1)
Elements leaving the viewport — dismissing panels, closing overlays. Exits decisively.
easing.spring
cubic-bezier(0.34, 1.56, 0.64, 1)
Playful overshoot for emphasis: popover appearance, drag-and-drop snap.

Z-Index

Named z-index layers prevent stacking conflicts across Electron's multi-overlay UI. Apply via z-index: var(--z-modal) or Tailwind utility z-modal.

Space

space.100 is the 4px base unit. Every token is a multiple of this base. Apply via padding: var(--space-400).

Graph Palette

Perceptually distinct colors for knowledge graph node types and edge weight encoding. The categorical palette has 8 hues that remain distinguishable in both light and dark modes. Toggle above to verify contrast.

Categorical — Node Types

8 semantic aliases map human-readable node types onto the categorical slots. Use background: var(--viz-node-code) or Tailwind bg-viz-node-code.

Sequential — Edge Weight / Relevance

5-step indigo scale from lowest (seq.1) to highest (seq.5) relevance or edge weight. Map a 0–1 score to a step. Darker = lower confidence; brighter = stronger connection.
